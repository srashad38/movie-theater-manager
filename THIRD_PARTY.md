# Third-party components

The runnable JAR bundles the unmodified H2 Database Engine 2.4.240 classes and resources. H2 is dual-licensed under MPL 2.0 or EPL 1.0. Its license and corresponding source are available from the official version tag:

- [H2 2.4.240 license text](https://github.com/h2database/h2database/blob/version-2.4.240/LICENSE.txt)
- [H2 2.4.240 corresponding source](https://github.com/h2database/h2database/tree/version-2.4.240)
- [H2 project](https://h2database.com/)

H2's own terms apply to that component independently of the application's license selection. No H2 source files have been modified.

JUnit Jupiter is a test-only dependency and is not bundled with the application. Maven plugins are build tools only. Java and Swing are supplied by the user's JDK installation.
